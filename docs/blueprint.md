# **App Name**: AgriConnect

## Core Features:

- Homepage UI: Display a homepage with a hero banner, navigation, and clear calls to action.
- Farmer Marketplace UI: Enable farmers to list crops with prices, and buyers to view, filter, and purchase crops.
- Equipment Rental/Purchase UI: Allow farmers to list and buyers to browse available equipment for rent or sale.
- Fair Price Calculator UI: Provide a fair price calculator where farmers input crop details to get a suggested price.
- Knowledge Hub UI: Display articles, tutorials, and videos focused on sustainable farming practices.
- AI Crop Recommendation Tool: Based on soil type and region input, suggest suitable crops for planting; this tool uses generative AI for optimized crop recommendations.
- Weather Forecast Widget: Display weather forecast information to help farmers know current local weather.

## Style Guidelines:

- Primary color: Earthy green (#8FBC8F) to represent agriculture and nature.
- Background color: Light beige (#F5F5DC) for a clean, modern backdrop.
- Accent color: Warm brown (#A0522D) to evoke trust and stability.
- Font pairing: 'Belleza' (sans-serif) for headlines and short text, 'Alegreya' (serif) for body text, which provides an elegant, readable feel. 
- Employ clean, modern icons related to farming, equipment, and weather, ensuring they are easily recognizable.
- Use a grid-based layout for consistent spacing and alignment, ensuring a responsive design that adapts to different screen sizes.
- Incorporate subtle animations and transitions to enhance user engagement without being distracting.
